Working title: AQF: Automatic Query Form Generation for Hierarchical JSON Electronic Health Records 

Abstract 

Problem: hierarchical JSON EHR data is difficult to query directly. 

Challenge: users know intent, but systems require path/schema knowledge. 

AQF: automatically generates bounded, executable, explainable query forms. 

Method: structure graph construction; content profiling; hierarchical queriability; operator-aware field scoring; bounded form synthesis; canonical query form model; form-to-query translation; query explainability. 

Scope: JSON, not XML; AQL-like examples only illustrate path-querying burden; query-level explainability, not predictive-model XAI. 

Evaluation: Easy / Medium / Hard workloads; Form Utility Score; ablation; performance; planned user study.
